# 🚀 Настройка репозитория на GitHub

## Способ 1: Автоматический (через GitHub CLI) ⚡

### Шаг 1: Установите GitHub CLI

1. Скачайте с [cli.github.com](https://cli.github.com/)
2. Установите GitHub CLI
3. Авторизуйтесь: `gh auth login`

### Шаг 2: Запустите автоматический скрипт

```bash
create-repo.bat
```

Скрипт автоматически:
- Инициализирует Git репозиторий
- Создаст коммит
- Создаст репозиторий на GitHub
- Отправит код на GitHub

---

## Способ 2: Ручной (через веб-интерфейс) 🌐

### Шаг 1: Создайте репозиторий на GitHub

1. Перейдите на [GitHub](https://github.com)
2. Нажмите кнопку **"New"** или **"+"** → **"New repository"**
3. Заполните форму:
   - **Repository name:** `caresync` (или другое имя)
   - **Description:** `Система управления здоровьем детей`
   - Выберите **Public** или **Private**
   - **НЕ** добавляйте README, .gitignore или лицензию (они уже есть)
4. Нажмите **"Create repository"**

### Шаг 2: Инициализируйте локальный репозиторий

Если Git еще не установлен, установите его (см. `УСТАНОВКА_GIT.md`)

Затем выполните:

```bash
# Инициализация репозитория
git init

# Добавление файлов
git add .

# Создание первого коммита
git commit -m "Initial commit: CareSync - Система управления здоровьем детей"
```

### Шаг 3: Подключите локальный репозиторий к GitHub

После создания репозитория GitHub покажет инструкции. Выполните:

```bash
# Добавьте remote (замените YOUR_USERNAME на ваш GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/caresync.git

# Переименуйте ветку в main (если нужно)
git branch -M main

# Отправьте код на GitHub
git push -u origin main
```

### Шаг 4: Проверка

Откройте ваш репозиторий на GitHub - все файлы должны быть там!

---

## Способ 3: Через init-git.bat (только локальная инициализация)

Если вы хотите только подготовить локальный репозиторий:

```bash
init-git.bat
```

Затем следуйте **Способу 2** для создания репозитория на GitHub.

## 📝 Дополнительные команды

### Обновление репозитория после изменений:

```bash
git add .
git commit -m "Описание изменений"
git push
```

### Создание новой ветки:

```bash
git checkout -b feature/название-функции
# ... внесите изменения ...
git add .
git commit -m "Добавлена новая функция"
git push -u origin feature/название-функции
```

### Клонирование репозитория:

```bash
git clone https://github.com/YOUR_USERNAME/caresync.git
cd caresync
```

## ⚠️ Важно

- **НЕ коммитьте** файлы с персональными данными (пути к PHP, пароли, токены)
- **НЕ коммитьте** базы данных (`.sqlite`, `.db`)
- Проверьте `.gitignore` перед коммитом

## 🔒 Безопасность

Если случайно закоммитили чувствительные данные:

1. Удалите файл из истории:
```bash
git filter-branch --force --index-filter "git rm --cached --ignore-unmatch путь/к/файлу" --prune-empty --tag-name-filter cat -- --all
```

2. Измените пароли/токены в реальных системах
3. Сделайте force push (осторожно!):
```bash
git push origin --force --all
```

## ❓ Проблемы?

### "Git не найден"
- Установите Git: см. `УСТАНОВКА_GIT.md`

### "Repository already exists"
- Репозиторий с таким именем уже существует
- Выберите другое имя или удалите существующий репозиторий

### "Permission denied"
- Проверьте авторизацию: `gh auth status`
- Или используйте HTTPS с токеном доступа

### "Failed to push"
- Проверьте подключение к интернету
- Убедитесь, что репозиторий создан на GitHub
- Проверьте правильность URL репозитория

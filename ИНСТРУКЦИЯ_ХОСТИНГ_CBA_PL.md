# Инструкция по загрузке на хостинг cba.pl

## 📋 Подготовка к загрузке

### Шаг 1: Подготовка файлов

1. **Backend (backend-php/):**
   - Скопируйте всю папку `backend-php/`
   - Переименуйте `.htaccess.production` в `.htaccess`
   - Обновите `config.php` или используйте `config.production.php`

2. **Frontend (html/):**
   - Скопируйте всю папку `html/`
   - Файл `config.js` уже настроен для хостинга

### Шаг 2: Настройка конфигурации

#### Backend (config.php):

1. Откройте `backend-php/config.php`
2. Измените JWT_SECRET на уникальный:
   ```php
   define('JWT_SECRET', 'ваш-уникальный-секретный-ключ-' . md5('что-то-уникальное'));
   ```

3. Проверьте путь к базе данных:
   ```php
   define('DB_PATH', __DIR__ . '/database.sqlite');
   ```

#### Frontend (config.js):

Файл уже настроен автоматически. API будет использовать `/api` на том же домене.

## 🚀 Загрузка на хостинг

### Вариант 1: Структура с подпапками (рекомендуется)

```
public_html/
├── api/              # backend-php/api/
│   ├── index.php
│   ├── auth.php
│   └── ...
├── backend-php/      # Остальные файлы backend
│   ├── config.php
│   ├── database.php
│   ├── utils/
│   └── database.sqlite
├── index.html        # html/index.html
├── login.html        # html/login.html
├── dashboard.html    # html/dashboard.html
├── js/               # html/js/
├── children/         # html/children/
└── health-records/   # html/health-records/
```

**Настройка:**
- В `html/config.js` измените: `apiUrl = '/api';`
- В `backend-php/.htaccess` раскомментируйте: `RewriteBase /api/`

### Вариант 2: Отдельные поддомены

**Backend на api.ваш-домен.cba.pl:**
```
api.ваш-домен.cba.pl/
├── api/
├── config.php
├── database.php
└── ...
```

**Frontend на ваш-домен.cba.pl:**
```
ваш-домен.cba.pl/
├── index.html
├── login.html
├── js/
└── ...
```

**Настройка:**
- В `html/config.js` измените: `apiUrl = 'https://api.ваш-домен.cba.pl/api';`

## 📤 Процесс загрузки

### Через FTP:

1. **Подключитесь к FTP:**
   - Хост: `ftp.ваш-домен.cba.pl` или IP адрес из панели
   - Логин: ваш логин
   - Пароль: ваш пароль
   - Порт: 21

2. **Загрузите файлы:**
   - Backend в папку `public_html/api/` или `public_html/backend-php/`
   - Frontend в папку `public_html/`

3. **Настройте права доступа:**
   - Папки: 755
   - Файлы: 644
   - `database.sqlite`: 666 (для записи)

### Через файловый менеджер:

1. Войдите в панель управления cba.pl
2. Откройте "Файловый менеджер"
3. Загрузите файлы через веб-интерфейс

## ⚙️ Настройка после загрузки

### 1. Создание базы данных

После загрузки backend автоматически создаст `database.sqlite` при первом запросе.

Или создайте вручную через скрипт:
```php
php create_test_users.php
```

### 2. Проверка .htaccess

Убедитесь, что файл `.htaccess` загружен и имеет правильные права (644).

### 3. Тестирование

1. Откройте ваш сайт: `https://ваш-домен.cba.pl`
2. Перейдите на: `https://ваш-домен.cba.pl/login.html`
3. Попробуйте войти с тестовыми данными

## 🔧 Решение проблем

### Ошибка 500 (Internal Server Error)

1. Проверьте права доступа к файлам
2. Проверьте логи ошибок в панели управления
3. Убедитесь, что PHP включен и версия 7.4+

### CORS ошибки

1. Проверьте настройки CORS в `config.php`
2. Убедитесь, что `.htaccess` загружен
3. Проверьте заголовки в браузере (F12 → Network)

### База данных не создается

1. Проверьте права на запись в папку backend-php
2. Убедитесь, что SQLite включен в PHP
3. Проверьте путь к базе данных в `config.php`

### API не работает

1. Проверьте путь к API в `html/config.js`
2. Убедитесь, что `.htaccess` правильно настроен
3. Проверьте логи ошибок

## 📝 Чек-лист перед загрузкой

- [ ] Изменен JWT_SECRET в `config.php`
- [ ] Настроен API URL в `html/config.js`
- [ ] Файл `.htaccess` переименован из `.htaccess.production`
- [ ] Права доступа настроены (755 для папок, 644 для файлов)
- [ ] База данных будет создана автоматически или загружена
- [ ] Тестовые пользователи созданы

## 🔐 Безопасность для продакшена

1. **Измените JWT_SECRET** на уникальный
2. **Отключите отображение ошибок** (уже в config.php)
3. **Защитите базу данных** через .htaccess
4. **Используйте HTTPS** (cba.pl обычно предоставляет SSL)
5. **Ограничьте CORS** только вашим доменом

## 📞 Поддержка

Если возникнут проблемы:
1. Проверьте логи ошибок в панели управления cba.pl
2. Используйте консоль браузера (F12) для отладки
3. Обратитесь в поддержку cba.pl

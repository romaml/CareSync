# CareSync - HTML Frontend

Статическая HTML версия веб-приложения CareSync. 

## ⚠️ ВАЖНО: Требуется Backend API!

HTML версия **не работает без backend API**. Вам нужен:
- PHP Backend (папка `backend-php` из проекта)
- Или доступ к работающему API серверу

## Структура файлов

```
html/
├── index.html              # Главная страница (редирект)
├── login.html              # Страница входа
├── dashboard.html          # Главная панель
├── history.html            # История активности
├── children/
│   ├── index.html          # Список всех детей
│   ├── detail.html         # Детали ребенка
│   └── new.html            # Добавление нового ребенка
├── health-records/
│   ├── index.html          # Список записей здоровья
│   └── new.html            # Добавление новой записи
└── js/
    ├── api.js              # API функции
    └── auth.js             # Функции аутентификации
```

## Как использовать

### Вариант 1: Открыть напрямую в браузере

1. Откройте файл `html/index.html` в браузере
2. Убедитесь, что бэкенд запущен на `http://localhost:8000`

### Вариант 2: Использовать локальный веб-сервер

#### Python 3:
```bash
cd html
python -m http.server 8080
```
Затем откройте `http://localhost:8080`

#### Node.js (http-server):
```bash
npx http-server html -p 8080
```

#### PHP:
```bash
cd html
php -S localhost:8080
```

## Требования

- ✅ Браузер с поддержкой ES6 модулей (современные браузеры)
- ✅ **Backend API** (PHP backend на порту 8000 или другой доступный API)
- ✅ Tailwind CSS загружается через CDN (требуется интернет-соединение)
- ✅ Веб-сервер для запуска (Python, Node.js, PHP или любой другой)

## Настройка API URL

По умолчанию API URL установлен как `http://localhost:8000/api`. 

**Чтобы изменить API URL, отредактируйте файл `config.js`:**

```javascript
// В config.js измените строку:
apiUrl = 'http://ВАШ_API_СЕРВЕР/api';
```

**Примеры:**
- Локальный сервер: `'http://localhost:8000/api'`
- Сеть: `'http://192.168.1.100:8000/api'` (IP адрес компьютера с API)
- Внешний API: `'https://api.example.com/api'`
- Хостинг: `'/api'` (если API на том же домене)

## Отличия от Next.js версии

- Нет серверного рендеринга (SSR)
- Нет оптимизации изображений
- Нет предварительной загрузки страниц
- Все страницы загружаются отдельно

## Поддержка браузеров

- Chrome/Edge (последние версии)
- Firefox (последние версии)
- Safari (последние версии)
- Не поддерживается Internet Explorer

## Примечания

- ⚠️ **Для работы требуется запущенный Backend API** (PHP backend)
- Все API запросы идут к backend серверу
- Данные хранятся в localStorage для токенов аутентификации
- При обновлении страницы состояние теряется (как и в обычных SPA)

## 🚀 Быстрый запуск

1. **Настройте `config.js`** (если API не на localhost:8000)
2. **Запустите:** `start.bat` или `python -m http.server 8080`
3. **Откройте:** `http://localhost:8080/login.html`

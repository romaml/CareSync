# Структура проекта CareSync

## 📁 Основные папки

### `Backend-Standalone/` - PHP Backend
Полный PHP Backend API, готовый к использованию.

**Запуск:** `start-server.bat`

### `Frontend-Standalone/` - HTML Frontend
Полный HTML Frontend, готовый к использованию.

**Запуск:** `start.bat`

### `docs/` - Документация
Техническая документация проекта.

### `mobile/` - Мобильное приложение
React Native приложение (опционально).

### `web/` - Next.js версия
Next.js версия фронтенда (опционально).

## 🚀 Использование

Обе папки (`Backend-Standalone` и `Frontend-Standalone`) независимы и могут использоваться отдельно или вместе.
